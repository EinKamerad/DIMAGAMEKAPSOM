# Инструкция запуска игры «BioFarme: Сердце Колонии»

## 1. Название игры и версия билда
- **Название медиапродукта:** «BioFarme: Сердце Колонии» (`BioFarme: Heart of the Colony`)
- **Версия сборки:** `1.0` (конкурсная релизная сборка)
- **Разрешение экрана:** `1920×1080` (Full HD, формат `16:9`, 2D)

## 2. Целевая операционная система и среда запуска
В строгом соответствии с п. 6.1 и разделом 7 конкурсного задания (сборки под ОС Windows не допускаются) проект подготовлен для двух целевых платформ:
1. **Веб-версия (WebGL для запуска с ПК)** — автономный локальный запуск в современных настольных браузерах (`Яндекс Браузер`, `Google Chrome`, `Chromium`, `Mozilla Firefox`, `Microsoft Edge`, `Safari`) на любой настольной ОС без доступа к интернету.
2. **ОС Astra Linux (`x86_64`)** — нативный исполняемый пакет `BioFarme.x86_64` для отечественной операционной системы Astra Linux Common Edition / Special Edition (без установки среды разработки Unity).

## 3. Пошаговая инструкция автономного запуска

### Вариант А — Веб-версия (WebGL, запуск с ПК без интернета)
Поскольку политика безопасности современных браузеров (`CORS`) блокирует прямое чтение WebAssembly-файлов по протоколу `file://`, папка `Build/BioFarme_WebGL/` укомплектована встроенным автономным локальным микро-сервером:
1. Распакуйте архив проекта в любую локальную директорию без спецсимволов и перейдите в папку `Build/BioFarme_WebGL/`.
2. **На Linux / Astra Linux / macOS:** откройте терминал в папке `Build/BioFarme_WebGL/` и выполните команду:
   ```bash
   chmod +x ./run_local_linux_mac.sh && ./run_local_linux_mac.sh
   ```
   *(Либо напрямую выполните `python3 run_local_web.py` или `python3 -m http.server 8080`).*
3. **На любом ПК с установленным Python 3:** запустите скрипт `run_local_web.py` — он автоматически поднимет локальный узел `http://localhost:8080` и откроет страницу `http://localhost:8080/index.html` в браузере по умолчанию.
4. Разверните окно браузера на полный экран (`F11`) при разрешении `1920×1080` и нажмите левую кнопку мыши в окне игры для активации звуковой подсистемы Web Audio.

### Вариант Б — Нативная сборка для ОС Astra Linux (`x86_64`)
1. Распакуйте папку `Build/BioFarme_AstraLinux/` на рабочую станцию под управлением Astra Linux (`x86_64`).
2. Откройте терминал в каталоге `Build/BioFarme_AstraLinux/` и предоставьте права на исполнение бинарному файлу и стартовому скрипту:
   ```bash
   chmod +x ./BioFarme.x86_64 ./run_biofarme.sh
   ```
3. Запустите игру командой:
   ```bash
   ./run_biofarme.sh
   ```
   *(или напрямую `./BioFarme.x86_64 -screen-width 1920 -screen-height 1080`). Установка Unity или сторонних пакетов не требуется.*

## 4. Управление (клавиатура и мышь, ПК-раскладка)

| Клавиша / Мышь | Назначение в игре |
| :--- | :--- |
| `W, A, S, D` / Стрелки | Перемещение био-инженера (в тактической паузе — свободная прокрутка камеры) |
| `Left Shift` | Спринт (ускоренное перемещение за счёт запаса выносливости) |
| `ЛКМ` | Основное действие выбранного инструмента, посадка семян или строительство |
| `ПКМ` | Орошение почвы 3×3 (распылителем) или демонтаж постройки с возвратом 70% ресурсов |
| `1–9, 0` / Колесо мыши | Переключение активного слота на нижней панели быстрого доступа |
| `E` | Взаимодействие с объектом рядом (сбор урожая, запуск мини-игр у Инкубатора и Сердца) |
| `Пробел (Space)` | Тактическая пауза (планирование застройки); в мини-игре синтеза — фиксация импульса |
| `B` или `Tab` | Открыть / закрыть окно «Био-Кодекс» (постройки + приоритеты сосудистой сети) |
| `M` | Открыть мини-игру «Био-синтез и мутационное орошение» |
| `H` | Открыть мини-игру «Дефибрилляция и подкормка Сердца» |
| `N` | Свернуть / развернуть миникарту |
| `Z / X`, `+ / -`, `Ctrl+Колесо` | Изменение масштаба обзора камеры |
| `F1` или `Esc` | Меню паузы, регулировка громкости и справка по управлению |

## 5. Известные ограничения, возможные ошибки и способы их устранения
1. **Ошибка при двойном клике по `index.html` напрямую (`file://`):** браузеры блокируют загрузку `.wasm` и `.data` без HTTP-протокола. *Решение:* всегда запускайте веб-версию через приложенный скрипт `run_local_web.py` (`http://localhost:8080/index.html`).
2. **Отсутствие звука в первые секунды в веб-браузере:** политика автовоспроизведения браузеров (`Autoplay Policy`) удерживает `AudioContext` до первого пользовательского клика. *Решение:* кликните ЛКМ в любой точке главного меню — фоновый эмбиент и звуковые эффекты включатся мгновенно.
3. **Занятый порт `8080` при локальном запуске:** если порт `8080` уже используется другой службой, выполните в папке веб-билда команду `python3 -m http.server 8090` и откройте `http://localhost:8090/index.html`.
4. **Масштабирование интерфейса на экранах с системным DPI 125% / 150%:** холст ПИ автоматически масштабируется под эталон `1920×1080` (`Scale With Screen Size`). Для идеальной пиксельной чёткости рекомендуется масштаб страницы браузера `100%` (`Ctrl + 0`) и полноэкранный режим (`F11`).
5. **Аппаратное ускорение WebGL 2.0:** при низкой кадровой частоте убедитесь, что в настройках браузера включён пункт «Использовать аппаратное ускорение, если доступно».
